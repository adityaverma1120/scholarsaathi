# Roadmap and Milestones

## 1. Delivery strategy

Build a complete, narrow journey before expanding the catalogue or
adding advanced automation. Each milestone should end with a working,
tested increment.

## 2. Milestone 0 --- Repository and product audit

Deliverables: - Current architecture map. - Inventory of existing
features. - Database/API inventory. - Deployment and Android build
audit. - Existing defects and security risks. - Requirements-to-code gap
matrix. - Final product name decision.

Exit criteria: no implementation starts until existing capabilities and
unknowns are documented.

## 3. Milestone 1 --- Product foundation

Deliverables: - Approved brand and navigation. - Student profile. -
Consent and privacy screens. - Secure document metadata/storage. - Basic
profile tests.

Exit criteria: student can create/edit a partial profile and manage
their own records.

## 4. Milestone 2 --- Document intelligence

Deliverables: - Upload validation. - OCR pipeline. - Field extraction. -
User correction workflow. - Readability checks. - Basic cross-document
comparison.

Exit criteria: a student can upload test documents, review extracted
values and understand uncertainty.

## 5. Milestone 3 --- Verified scholarship catalogue

Deliverables: - Scheme data model. - Admin source/review workflow. -
Initial verified NSP and UP schemes. - Academic-year and deadline
handling. - Source links and verification dates.

Exit criteria: every published scheme has reviewed official evidence.

## 6. Milestone 4 --- Eligibility and readiness

Deliverables: - Rule engine. - PASS/FAIL/UNKNOWN evaluation. -
Explainable results. - Scheme-specific document matching. - Readiness
checklist.

Exit criteria: test cases prove missing/unverified rules do not generate
positive certainty.

## 7. Milestone 5 --- Application assistance

Deliverables: - Field-by-field instructions. - Profile-to-form
mapping. - Student review and copy workflow. - Final application
checklist. - Status tracking and grievance drafts.

Exit criteria: no unauthorised portal submission or security bypass.

## 8. Milestone 6 --- AI assistant and notifications

Deliverables: - Curated RAG index. - Grounded answers and citations. -
Hindi/English quality tests. - Deadline and renewal reminders. -
Provider outage fallback.

Exit criteria: verified answers are traceable; unsupported answers admit
uncertainty.

## 9. Milestone 7 --- Expansion

-   Additional state schemes.
-   Institution/private scholarship sources.
-   Official verification integrations where authorised.
-   More languages.
-   Expanded accessibility and analytics.

Exit criteria: each new source has an owner, update process and quality
test.

## 10. Release gates

At every milestone: - Review privacy impact. - Run regression tests. -
Check mobile/Android layout. - Confirm no demo data is presented as
real. - Update documentation. - Record remaining limitations.
